# Проект сервиса управления рассылками с возможностью администрирования и получения статистики. Создан на фреймворке Django, с визуальным оформлением страниц и простым веб-приложением (создан в учебных целях).

1. В проекте реализован проект HTML-кода страниц сервиса с использованием библиотеки стилей Bootstrap.

## Использование

1. Запустить сервер командой `python manage.py runserver`
2. В терминале перейти по ссылке вида 'http://localhost:8080' или 'http://127.0.0.1:8000'.
3. Для быстрой отправки рассылки через терминал выполнить команду:
   3.1. Отправить конкретную рассылку (напр. под названием 1): `python manage.py send_mailing --mailing-id 1`
   3.2. Посмотреть помощь: `python manage.py send_mailing --help`
